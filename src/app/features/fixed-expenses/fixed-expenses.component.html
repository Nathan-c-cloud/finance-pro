Ce référentiel sert de modèle. Le modifier n'affecte jamais les mois déjà créés : sur la page Mois, le bouton "Ajouter les dépenses fixes" copie les dépenses actives, figées, dans le mois affiché. Saisis le montant de la période (12 € pour une dépense annuelle) : chaque mois reçoit sa part. Le jour de prélèvement est facultatif : s'il est renseigné (de 1 à 31), c'est exactement ce jour que reçoit la transaction quand la dépense est ajoutée à un mois (si le mois est plus court, ce sera son dernier jour). Laissé vide, la transaction est ajoutée sans date.

Pour un virement qui revient chaque mois (ton épargne, par exemple), choisis « Virement vers » dans la liste Catégorie : à l'ajout au mois, la sortie est créée sur ce compte et l'entrée sur le compte de destination. Le jour de prélèvement est alors obligatoire. Ça compte comme de l'épargne si le compte de destination est un compte d'épargne.
